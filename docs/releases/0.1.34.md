# Product 0.1.34

Status: selected; build and production upgrade pending.

The Web shell no longer scrolls the whole page. A Library source with code
blocks made the document taller than the window, because each copy button's
screen-reader label is absolutely positioned and its nearest positioned
ancestor was the root, outside the reader's scroll pane. A wheel over the
sidebar then scrolled the page into blank space. The shell is now that
ancestor and clips its content. The run list under a thread scrolls within
30% of the window height so the shell clip cannot cut off older runs.

On a desktop-width window the operator can drag the sidebar's border and the
boundary between a list and its reader in Library and Research. The handles
also take the arrow keys (Shift for larger steps, Home and End for the
limits). A double click or Enter returns a boundary to its default. Widths
are kept in the browser's local storage. The sidebar stays between 200px and
480px and leaves at least 672px for the view; a list keeps at least 240px and
leaves its reader at least 360px. Phones keep the drawer and single column.

The Control schema stays 21 and the worker `hermes-0.15.0-gen10` is unchanged,
so an upgrade from 0.1.33 is code-only.
