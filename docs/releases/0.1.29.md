# Product 0.1.29

Status: deployed; isolated lifecycle, 28 -> 29 upgrade and rollback rehearsal, and
production upgrade passed. Published as GitHub release `v0.1.29`.

This release carries #42, which closes gaps and regressions in 0.1.28's
retrieval query cleanup and section-aware evidence windows. The Control schema
stays 20 and the worker `hermes-0.15.0-gen10` is unchanged, so an upgrade from
0.1.28 is code-only.

**Retrieval query.** Length requirements are removed in more phrasings: a CJK
unit followed directly by an answer verb (`300字总结…`), `字数` after 请把 or
请将, an English unit with 个 (`500个tokens`), and a length before 写作文. Counts
that belong to a term stay: a compound noun that starts with a verb (分析法,
写作技巧, 描述符, 说明书) and an English unit word that starts a hyphenated name
(`Token-Merging`). A label-led citation bracket is removed together with the
link it starts, and link destinations are recognized at any nesting depth, so
destination and title words do not become search terms.

**Evidence windows.** A metadata title that keeps the export API's line break
still marks the converted page's title, and so does a converted title whose
small capitals split letters from their words. A converted page without its own
title keeps its first level-1 section, so a Limitations section right after the
title is selected again.
