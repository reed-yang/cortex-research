# Cortex Research 0.1.21

Status: source validated; candidate build and installed acceptance pending.

## Changes

- Recover transient arXiv export-API failures through a product-bound HTTPS abs
  endpoint. Validate paper identity and required citation metadata before use.
- Keep metadata failures known and retain both endpoint errors if recovery fails.
- Exclude preexisting unrelated engine processes from the child's survivor scan
  so they cannot invalidate an otherwise successful effect.
- Run the provider-free engine and research suites in hosted checks.

## Validation and limits

The real child acceptance exercised four failed API attempts, abs fallback,
HTML parsing, corpus writes and indexing against a loopback fixture. The related
engine/research suite passed 320 tests across the full run and one corrected
assertion rerun; Control, artifact and release-record checks passed 385 tests.

Product 0.1.21 selects installation sequence 21, retains Control schema 19 and
qualified Hermes 0.15.0-gen9, and adds no dependency or credential requirement.
PDF-only ingestion remains outside the supported capability. This release does
not implement cross-process or cross-machine rate coordination and does not
claim to eliminate external arXiv capacity failures.
