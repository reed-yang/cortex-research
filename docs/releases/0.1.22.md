# Cortex Research 0.1.22

Status: source validated; installed acceptance pending.

## Behavior

The default path reads metadata from the direct HTTPS abs page and full text
from the direct HTML page. A valid abs response makes zero export API calls.
If the abs request fails or its metadata fails validation, the export API is
used as a fallback. Both endpoint failures remain a known metadata refusal
before corpus writes, with both causes reported. API error feeds or mismatched
paper identities are rejected.

The existing HTTP client performs direct downloads; no curl runtime dependency
is added. The abs page is attempted once before the API retry budget. The
existing HTML conversion preserves its math and figure handling. PDF-only
papers remain unsupported by strict product ingestion; no OCR support or
archive-only source state is introduced.

## Validation and composition

326 engine/research tests passed, including real child ingestion and indexing
with a deliberately unavailable API and zero API requests on the normal path.
The API fallback was also exercised through a real child after abs404.

Product 0.1.22 selects sequence 22, Control schema 19 and qualified Hermes
generation 9. No dependencies, credentials, database migrations, metadata-cache
schema or cross-machine request coordinator are added. Existing captures are
not automatically resubmitted by this release.
