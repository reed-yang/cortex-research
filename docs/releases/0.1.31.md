# Product 0.1.31

Status: built and installed on the operator host on 2026-10-07 (code-only
upgrade from 0.1.30; Control schema 21 and native sessions unchanged).

This release carries #55. XHS image OCR now runs the configured Responses
model first, at low effort, then Novita DeepSeek-OCR-2, then GLM. The
Responses model reads the vertical arXiv stamp on a paper's first page, and
an XHS paper recommendation is importable only with an arXiv ID its image
writes. The Control schema stays 21 and the worker `hermes-0.15.0-gen10` is
unchanged, so an upgrade from 0.1.30 is code-only.
