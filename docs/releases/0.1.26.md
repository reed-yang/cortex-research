# Product 0.1.26

Status: candidate; packaging and installed acceptance in progress.

The product now resolves explicit `age://store/VARIABLE_NAME` credential
references in addition to Keychain. This repairs the gap where a local encrypted
store contained engine credentials but the supervised runtime could not use
them. Existing references and provider routing remain authoritative; plaintext
is decrypted in memory, never sourced as shell code or written to configuration.

The supervised engine accepts both durable stores, and doctor recognizes age
provider/transport references. A checkout-only operator wrapper injects declared
engine bindings into a trusted command. Managed model tools retain their
credential-free environment and denied access to the encrypted store/identity.

Focused tests cover invalid references, parsing without shell execution,
redaction, timeouts, rotation, scoped child environments and doctor behavior.
The Control schema remains 19; worker `hermes-0.15.0-gen10` is unchanged.
