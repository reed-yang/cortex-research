# Product 0.1.26

Status: deployed; isolated lifecycle and installed credential acceptance passed.

The product now resolves explicit `age://store/VARIABLE_NAME` credential
references in addition to Keychain. This repairs the gap where a local encrypted
store contained engine credentials but the supervised runtime could not use
them. Existing references and provider routing remain authoritative; plaintext
is decrypted in memory, never sourced as shell code or written to configuration.

The supervised engine accepts both durable stores, and doctor recognizes age
provider/transport references. A checkout-only operator wrapper injects declared
engine bindings into a trusted command. Managed model tools retain their
credential-free environment and denied access to the encrypted store/identity.

Focused tests cover invalid references, parsing without shell execution,
redaction, timeouts, rotation, scoped child environments and doctor behavior.
The Control schema remains 19; worker `hermes-0.15.0-gen10` is unchanged.

The candidate bundle passed verification and isolated install/start/status/doctor/
stop checks. Production was archived while quiescent and upgraded through the
supported installer. Missing GLM and Novita references were added from the
existing age store; OpenRouter and model-provider references were preserved.
The installed interpreter resolved all four engine aliases with no ambient
credentials and verified a scoped child environment. The live Web is healthy,
the gen10 worker is launched and bound, and all seven runtime bindings, eight
native sessions and 56 messages were preserved. No Telegram message was sent.

Validation covered 605 distinct tests: the expanded run passed 604 cases and
exposed one incomplete new test fixture; after supplying its required endpoint,
all 19 age tests passed. No product failure remained. Actual GLM-OCR using the
shared age resolver also processed the requested 39-page paper through the
separately installed skill's existing page-image mode; the earlier whole-PDF URL
requests timed out. OCR acceptance does not imply bundled PDF-engine support.
