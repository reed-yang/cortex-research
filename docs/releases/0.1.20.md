## Distribution boundaries

The sealed controller bundle includes its CPython supply and built Web payload.
Installation takes an explicit host-supplied compatible Node executable. Hermes
is provisioned independently; no operator worker slot, credentials, sessions,
research data or deployment archive is included in a public asset.

Binary packaging retains the sealed bundle unchanged and places supplemental
third-party notices beside it. Package license declarations without a recovered
upstream notice are identified explicitly; standard license reference text is
labelled as such and no copyright holder/year is invented.

No license has yet been selected for Cortex Research's own code. Public source
visibility must not be described as a selected open-source license.

## Functional boundary

`/research` conducts research over adopted evidence and retained dossiers. It
does not restart autonomous legacy idea/exploration engines, introduce a second
profile, or upgrade Hermes. Cross-generation activation and native continuity
remain separate acceptance gates for any future worker upgrade.
