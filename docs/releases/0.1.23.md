# Cortex Research 0.1.23

This release adds opt-in publication from adopted corpus papers to an existing
readings library. Product version 0.1.23 selects installation sequence 23,
Control schema 19 and the qualified Hermes generation 9. No Control migration,
worker upgrade or automatic destination selection is introduced.

New paper directories publish exclusively. Existing notes and manually modified
files are protected; generated-file updates require a matching ownership receipt.
Unowned existing directories require an unambiguous arXiv identity; a matching
related-work citation or a different hostname cannot establish ownership.
A separate durable journal records attempts, retained before/after snapshots and
recovery state. macOS confines the publisher child and protects the configured
destination from Capture child writes. Publication status appears in Library,
the authenticated API and the CLI independently of internal import.

The [runbook](../runbooks/readings-publication.md) documents explicit enablement,
the same-filesystem requirement, first-enable baseline, retry, backups and
rollback. Generated-file updates are in place, so unknown partial writes stop
for operator reconciliation. Existing adopted sources are not bulk-exported.
PDF download, OCR, translation, external indexing and cloud sync are not added.

Source validation includes real sandboxed publisher and daemon tests against
disposable libraries, offline Capture integration, and Web contract/UI checks.
The release descriptor selects build inputs rather than proving installed state.
Actual reviewed commits, hosted review findings and mini upgrade/health results
are recorded in the associated PR and deployment evidence. A working status
endpoint alone does not establish live external publication or model delivery.
