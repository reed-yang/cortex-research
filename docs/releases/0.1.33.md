# Product 0.1.33

Status: selected; build and production upgrade pending.

A blog import whose page extracts under 2,000 characters now also fetches
Jina's copy and keeps the longer one. Script-rendered pages such as LessWrong
posts extracted as a few lines of page chrome before this. `cortex xhs
refetch-blog <source id>` fetches an imported blog again and writes its next
version; the blog stays imported, and a failed fetch leaves it as it was. The
Control schema stays 21 and the worker `hermes-0.15.0-gen10` is unchanged, so
an upgrade from 0.1.32 is code-only.
