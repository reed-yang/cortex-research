# Product 0.1.30

Status: candidate; not built from merged main, not deployed.

The Library reads stored documents as rendered Markdown, and XHS notes and blogs
become Library sources beside papers. Control moves to schema 21; the worker
`hermes-0.15.0-gen10` is unchanged.

**Library reader.** Notes, Full text and Grounding open in Preview, which
renders the whole stored document (up to 2 MiB) with the chat's Markdown and
math renderer and the source's own figures. Source is the paged, line-numbered
citation view. Figures load only from the selected source's own `assets/`
directory through a new asset route; remote images are not loaded. See
[the plan](../plans/library-reader.md).

**XHS notes and blogs.** An opt-in plugin follows chosen XHS bloggers, pulls
their notes once a day through TikHub, transcribes every carousel image with
cloud OCR, and identifies the papers and blogs each note recommends. The Library
gains a kind filter and a note page that lists recommendations with their image
and verbatim transcription; papers import through the existing Capture flow, and
blogs are fetched and stored as `blog` sources, each linked back to the note
that recommended it. The plugin is disabled by default and needs
`cortex xhs init-roots`, configuration and credential references before it runs.
Notes and blogs are not yet research evidence. See [the plan](../plans/xhs-sources.md)
and [the runbook](../runbooks/xhs.md).

Migration 21 adds the XHS, content-binding and source-link tables and rebuilds
`research_schedules` to admit two disabled XHS jobs, keeping every existing row.
`state_archive.py` accepts schema 21, so a 20 -> 21 upgrade gets a baseline
archive and recovery script. The research package now depends on
`trafilatura` for blog extraction, so the Python dependency closure changes and
the 0.1.20 notices cannot be reused for a public release archive.
